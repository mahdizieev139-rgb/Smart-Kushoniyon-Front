# Супориш ба Backend (Smart-Kushoniyon-Back)

**Мақсад:** ба ҳамаи мағозаҳо рақами мағоза (`shopNumber`) гузоштан ва ба ҳар мағоза маҳсулоти мувофиқ илова кардан.

**Ҳолати ҳозира дар DB:** 10 мағоза мавҷуд, вале `shopNumber` барои ҳама `null`; ҳамагӣ 3 маҳсулот сабт шудааст (аксари мағозаҳо маҳсулот надоранд).

---

## Вазифаи 0 — Пешванди «DEMO»-ро аз номҳо нест кардан (МУҲИМ)
Дар `prisma/seed.ts` ҳамаи номҳо бо «DEMO » оғоз мешаванд (мисол: `DEMO Кошини Соҳибкор`). Ин дар сайт бад менамояд.

- **Дар DB аллакай тоза шуд** (бо SQL `UPDATE ... regexp_replace(name,'^DEMO\s+','')` дар ҳамаи ҷадвалҳои `*_translations`).
- **Лутфан дар `seed.ts` низ доимӣ кунед:** пешванди `DEMO ` -ро аз ҳамаи номҳои мағоза/маҳсулот/категория/дарвоза/қатор бардоред, то аз нав seed кардан «DEMO»-ро барнагардонад. (Майдони `isDemo = true` метавонад боқӣ монад — он танҳо нишонаи дохилист, на дар ном.)

---

## ⚠️ Нуктаи техникӣ (муҳим)
Дар `prisma/seed.ts` ҳамаи upsert-ҳо `update: {}` доранд — яъне **аз нав иҷро кардани seed мағозаҳои мавҷударо навсозӣ намекунад**. Барои пур кардани `shopNumber` ё маҳсулоти мағозаҳои аллакай сохташуда яке аз инҳоро кунед:
- `update` блокро тағйир диҳед, то `shopNumber` (ва ғ.)-ро нав кунад, **ё**
- як скрипти алоҳидаи навсозӣ (update) нависед, **ё**
- DB-ро аз нав reset + seed кунед (`prisma migrate reset`).

Калиди unique барои мағоза = `slug`.

## Вазифаи 2 — Маҳсулот барои ҳар мағоза

Ба ҳар мағоза 2–3 маҳсулоти мувофиқ илова кунед (бо тарҷумаҳои tj/ru/en, `price` Decimal, `currency='TJS'`, `status='APPROVED'`, `availability='IN_STOCK'`, категорияи дуруст). Нархҳо намунавӣ — метавонед тағйир диҳед.

**Кошинфурӯшӣ (категория: Кошинҳо)**
- DEMO Кошини Соҳибкор → Кошини сафед 60×60 — 45 TJS · Кошини фарши гранит — 85 TJS
- DEMO Кошини Памир → Кошини девор 30×60 — 38 TJS · Кошини ҳаммом — 52 TJS

**Рангфурӯшӣ (категория: Рангҳо)**
- DEMO Ранги Душанбе → Ранги обии дохилӣ 10л — 120 TJS · Ранги фасад 10л — 180 TJS
- DEMO Ранги Ватан → Эмали сафед 2.5кг — 65 TJS · Грунтовка 10л — 95 TJS

**Сантехника (категория: Сантехника)**
- DEMO Сантехникаи Нур → Крани обгарм — 85 TJS · Трубаи PPR 25мм — 9 TJS/м
- DEMO Сантехникаи Оби Зулол → Унитаз — 650 TJS · Смеситель — 140 TJS

**Асбоб (категория: Асбобҳо)**
- DEMO Асбоби Устод → Дрел — 420 TJS · Болғар 125мм — 310 TJS
- DEMO Асбоби Қувват → Шуруповерт — 380 TJS · Маҷмӯи калидҳо — 150 TJS

## Санҷиш пас аз иҷро
```bash
# Ҳамаи мағозаҳо бояд shopNumber дошта бошанд:
psql -U postgres -d kushoniyon -c "SELECT \"shopNumber\", slug FROM shops ORDER BY \"shopNumber\";"
# Ҳар мағоза бояд маҳсулот дошта бошад:
psql -U postgres -d kushoniyon -c "SELECT s.slug, count(p.id) FROM shops s LEFT JOIN products p ON p.\"shopId\"=s.id GROUP BY s.slug;"
```
Инчунин: `GET http://localhost:4000/api/v1/shops?locale=tj` — `shopNumber` бояд пур бошад.
